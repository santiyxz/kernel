Which build is this?

Run /stats in your server for uptime and the host, and /ping for gateway and API latency. /help prints the command map generated from the build that is actually running, so a missing command means the server has not restarted yet.

Which one is not us

There is no “Kernel Pro”, “Kernel Premium bot” or DM that asks you to re-authorise an account. The invite on this site and the support server are the only ones Kernel publishes. Anything else is not affiliated with this project.

Why no sibling bots

  • One codebase. Every build runs the same code; the test build just receives changes earlier, so a bug is one bot to fix, not two.
  • One invite. Adding a second bot would double the permissions on your server for no extra feature.
  • One status page. The live status and the external probe watch the bot you actually invited, not a fleet.

Missing a build you expected? Send a message and ask — the answer will be the real state, not a placeholder.
