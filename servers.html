Getting listed

Invite Kernel and run /setup. Servers appear once the bot is in them and the public settings API can see them. Nothing needs to be requested, and nothing can be bought — there is no featured slot and no tier that moves a server to the front.

Member counts

Counts come from Discord's cached member count at the time the bot last refreshed. They can lag after a large purge or a raid. When the total is zero — usually a freshly created server — the number is hidden rather than printed as praise.

Removal

Removing Kernel removes the server from this list automatically. If the bot is gone and the card is still here, the cached payload has not expired yet; it clears on the next refresh. To force it sooner, send a message with the server id.
