Privacy

Every record Kernel keeps, in one list.

Short version: no passwords, no IP addresses, no analytics scripts, no advertising pixels. The long version is the list below — if something is not on it, the site and bot do not store it.

Read the terms

What is stored

RecordContentsWhy
Server settingsGuild id, channel ids, role ids, module switchesSo commands know where to log and what is enabled
CasesCase id, guild id, target id, moderator id, reason, timestampModeration history the staff asked for
Verification grantGuild id, member id, timestampTo stop the gate asking twice
Premium grantDiscord user id, tier, granted dateTo check a role; granted by hand
ReviewsDiscord user id, username, rating, text, timestampPublished reviews and one-per-account enforcement
Contact messagesName, email, subject, message, timestampSo the owner can reply

What is not stored

  • No Discord password. Sign-in is OAuth; the password never leaves Discord.
  • No IP addresses or location. Neither the site nor the bot writes an IP to disk.
  • No login history. A session ends when the browser tab closes or the token expires.
  • No permanent message archive. Automod inspects a message to decide, then discards it. The last ten deleted messages per channel stay in memory for /snipe and vanish on restart; a configured log event also posts what it was set to log in that channel.
  • No analytics, cookies or pixels. There is no Google Analytics, no ad script, no fingerprinting.

Dashboard session

After Discord sign-in, the access token is kept in sessionStorage for that tab only. It is sent to the Kernel API as a bearer token, never to a third party. Closing the tab discards it; logging out clears it immediately.

The dashboard decides what you can see from your Discord id and your roles in the selected server. A member without a staff role receives a 404 from the owner API, not a list of hidden features.

Third parties

  • Discord — OAuth sign-in and the bot connection.
  • Hosting — GitHub Pages serves this site; the bot runs on a separate host.
  • Payment provider — Premium opens an external payment page. Card details go to that provider; Kernel never sees them.
  • Fonts — Google Fonts serves Inter and JetBrains Mono. If that request is blocked, the site falls back to system fonts.

Removal

Removing Kernel from a server deletes that server's settings on the next cleanup. To remove a case, a review or a Premium grant tied to your account, send a message with the server id and what should go; the owner answers and deletes it. There is no automated export because there is nothing beyond the rows listed above.
